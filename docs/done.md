# Что значит «харнес доделан»

Закрытый список универсальной части. Настройка экземпляра (пакеты организации и человека, сценарии, перенос старой памяти) сюда не входит: она идёт после.

Порядок работы: блок за блоком сверху вниз. После каждого блока список обновляется.

## Память

- [x] Запись это файл, который читает человек, в каталоге экземпляра
- [x] Типы записей и статусы: черновик, действует, устарела, заменена, удалена
- [x] Окно вето, срок задаёт пакет
- [x] Привязка к месту с отпечатком, устаревание при изменении места
- [x] Использование по ссылке на идентификатор в отчёте, устаревание без ссылок
- [x] Решение только от человека и только с причиной, замена старого решения
- [x] Очистка секретов до записи
- [x] Ввоз записей из другого хранилища
- [x] Записи во входе задачи сценария, с пределом размера
- [x] Записи проекта в старте сессии, в пределе размера, самые цитируемые первыми
- [x] Отметка «это было неверно»: `reins memory wrong <id>`; запись уходит в конец, после второй отметки она «устарела»
- [x] Общая область: `reins memory share <id>` делает запись записью всех проектов
- [ ] Запись не становится общей сама, когда подтвердилась в двух проектах
- [ ] Поля дела: внешний статус, число переносов, следующий шаг
- [ ] Срок хранения удалённых записей
- [ ] Производный индекс: поиск по словам
- [ ] Отпечаток каждого места записи, а не только первого, и места-каталога
- [ ] Блокировка счётчиков использования при одновременных отчётах

Формат хранения менялся один раз: записи `.json` из каталога состояния больше не читаются. Настоящих записей в старом формате не было.

## Контур задачи

- [x] Состояния, события с источником, блокировка, срок задачи, остановка человеком, публикация
- [x] Задача сценария привязана к сессии клиента: её конверт отвечает только этой сессии
- [x] Задача с договором: агент предлагает, код проверяет как манифест, человек утверждает
- [x] Несколько исполнителей: роли и число из манифеста, вне сценария предел пакета
- [x] Поле манифеста «модель»: уровень во входе задачи, имя модели из пакета, один подъём уровня
- [x] Приостановка задачи новым сценарием в той же сессии и продолжение в другой сессии
- [x] Отчёт подчинённого исполнителя судит код: сверка его цитат с источником задачи
- [x] Учёт токенов задачи и предел `token_limit`: задача сверх предела ждёт человека
- [x] Договор: задача, которой нужна запись вне договора, останавливается
- [x] Слова человека для задачи, которая ждёт: `reins approve <задача>`, `reins retry <задача>`
- [ ] Отчёт подчинённого без текста не судится. Claude Code: поле `last_assistant_message` события не проверено в живом клиенте. Ответ FAIL только пишется в журнал
- [ ] Токены подчинённых исполнителей Claude Code могут лежать в отдельных файлах: в предел задачи они тогда не входят
- [ ] Учёт токенов в Claude Code читает файл сессии клиента: форма файла не проверена в живом клиенте
- [ ] Чтение через коннектор вне договора договор не останавливает: у инструмента чтения нет имени коннектора

## Политика

- [x] Слои, конверт задачи, правила пакетов, пауза, защита самого харнеса
- [x] Разбор команды оболочки для защиты путей: запись в состояние, память и конфигурацию получает отказ
- [x] Правила `gate` по уровням пакетов: раздел `gate` пакета добавляет списки и формы команд
- [x] Очередь отложенных действий: `reins queue`, одобрение пропускает тот же вызов один раз
- [ ] Путь, который строит переменная или скрипт, разбор не видит (остаётся совпадение текста)
- [x] Очередь: действие ждёт неделю, законченные записи хранятся ещё неделю, чистит `reins sweep`
- [x] Очередь: человек видит команду целиком; одобрение относится к команде, а не к словам агента рядом с ней
- [x] Формы `gate`: форма с отказом стоит раньше формы с вопросом, какой бы пакет её ни дал
- [ ] Сроки очереди заданы в коде, а не в пакете

## Проверка готовности

- [x] Ответ привязан к состоянию работы: после изменения работы публикация кончается с меткой «не проверено»
- [x] Скрипт проверки и скрипт сбора: переменные только коннекторов чтения из манифеста, изменение работы клиента это отказ сбора
- [ ] Песочница системы для скриптов пакета: сеть и файлы вне работы не ограничены
- [ ] Работа вне репозитория git не имеет отпечатка: ответ к ней не привязан

## Журнал

- [x] Запись с проверкой строки, счётчики за период
- [x] Восемь метрик спецификации по именам, за неделю и за неделю до неё: `reins status`, раздел `eight`
- [x] Поля данных для всех видов событий, которые пишет код
- [x] Ротация файла: предел размера, архив, срок архива задаёт пакет
- [x] Ответ человека «да» на вопрос об одном действии пишется в журнал
- [ ] Метрики «стоимость на сценарий» и «эффект предложений» пусты: строк расхода и замера эффекта ещё никто не пишет
- [ ] Ответ человека «нет» в журнал не попадает: клиент о нём не сообщает
- [ ] Доля «да» занижена в режимах клиента без вопросов и при сбое инструмента после «да»: вопрос считается, ответ не пишется
- [ ] Задержка хука «после действия» на каждом инструменте не замерена в живом клиенте

## Крафт

- [x] Два детектора, одно предложение на шаблон, решение человека
- [x] Замер эффекта принятого предложения: через неделю, тот же сценарий или правило до и после
- [x] Детекторы: повтор договоров как кандидат в сценарий, запись памяти без использования
- [x] Предложение с готовой правкой: манифест в пакет человека, запись памяти в «устарела»
- [x] Отклонённый паттерн предлагается снова, только когда вырос вдвое
- [ ] Остальные детекторы схемы: повтор цепочки действий, повтор ошибки инструмента, уровень модели, неиспользуемый сценарий
- [ ] Пороги и предел предложений в неделю из пакета; пометка сценария «не трогать»; откат как предложение
- [ ] Текст предложения пишет код, а не модель; недельной сводки файлом нет

## Клиент

- [x] Команда `reins`, события «перед» и «после» действия, события сессии, адаптер Claude Code
- [x] Событие «перед сжатием контекста»: старт после сжатия называет задачу сессии
- [x] События подчинённых исполнителей: запуск, отчёт, действие подчинённого с ролью и родительской задачей
- [x] Определение уровня клиента при старте: полный, без вопроса с выбором, без события «до»
- [x] Запуск без окна: вопрос становится местом в очереди
- [x] Второй клиент `clients/stdio`: то же ядро через свой кодек, ядро не называет клиентов
- [ ] Уровень клиента задаёт адаптер, а не замер: харнес не проверяет, что событие «до» приходит
- [x] Запуск сценария без окна одной командой: `reins run <сценарий>` открывает задачу и запускает клиент машины
- [ ] Команду клиента без окна (`runner`) задаёт конфигурация машины: для Claude Code она не проверена в живом клиенте
- [ ] По пределу времени харнес останавливает только сам клиент: процессы, которые клиент запустил, могут остаться
- [ ] Ответ «вернуть отчёт» и «добавить во вход» вне старта сессии клиенту не передаются
