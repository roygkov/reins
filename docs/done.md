# Что значит «харнес доделан»

Закрытый список универсальной части. Настройка экземпляра (пакеты организации и человека, сценарии, перенос старой памяти) сюда не входит: она идёт после.

Порядок работы: блок за блоком сверху вниз. После каждого блока список обновляется.

## Память

- [x] Запись это файл, который читает человек, в каталоге экземпляра
- [x] Типы записей и статусы: черновик, действует, устарела, заменена, удалена
- [x] Окно вето, срок задаёт пакет
- [x] Привязка к месту с отпечатком, устаревание при изменении места
- [x] Использование по ссылке на идентификатор в отчёте, устаревание без ссылок
- [x] Решение только от человека и только с причиной, замена старого решения
- [x] Очистка секретов до записи
- [x] Ввоз записей из другого хранилища
- [x] Записи во входе задачи сценария, с пределом размера
- [ ] Записи в старте сессии по месту работы, а не только очередь вето
- [ ] Отметка «это было неверно» и падение веса записи
- [ ] Общая область: запись для всех проектов
- [ ] Поля дела: внешний статус, число переносов, следующий шаг
- [ ] Срок хранения удалённых записей
- [ ] Производный индекс: поиск по словам
- [ ] Отпечаток каждого места записи, а не только первого, и места-каталога
- [ ] Блокировка счётчиков использования при одновременных отчётах

Формат хранения менялся один раз: записи `.json` из каталога состояния больше не читаются. Настоящих записей в старом формате не было.

- [x] Задача с договором: агент предлагает, код проверяет как манифест, человек утверждает

- [x] Приостановка задачи новым сценарием в той же сессии и продолжение в другой сессии
