# Что значит «харнес доделан»

Закрытый список универсальной части. Настройка экземпляра (пакеты организации и человека, сценарии, перенос старой памяти) сюда не входит: она идёт после.

Порядок работы: блок за блоком сверху вниз. После каждого блока список обновляется.

## Память

- [x] Запись это файл, который читает человек, в каталоге экземпляра
- [x] Типы записей и статусы: черновик, действует, устарела, заменена, удалена
- [x] Окно вето, срок задаёт пакет
- [x] Привязка к месту с отпечатком, устаревание при изменении места
- [x] Использование по ссылке на идентификатор в отчёте, устаревание без ссылок
- [x] Решение только от человека и только с причиной, замена старого решения
- [x] Очистка секретов до записи
- [x] Ввоз записей из другого хранилища
- [x] Записи во входе задачи сценария, с пределом размера
- [x] Записи проекта в старте сессии, в пределе размера, самые цитируемые первыми
- [x] Отметка «это было неверно»: `reins memory wrong <id>`; запись уходит в конец, после второй отметки она «устарела»
- [x] Общая область: `reins memory share <id>` делает запись записью всех проектов
- [ ] Запись не становится общей сама, когда подтвердилась в двух проектах
- [x] Дело: следующий шаг, внешний статус, счёт дней переноса; шаг и закрытие командами `reins memory next` и `reins memory close`; открытые дела в старте сессии
- [x] Слова человека для дела: `reins memory step <дело> <шаг>` и `reins memory end <дело>`; клиент с хуком спрашивает человека перед ними
- [ ] Дело не закрывается само по внешнему статусу
- [x] История записей: с ключом конфигурации `memory_commit` харнес сам коммитит файлы записей в конце команды или хука; чужие файлы каталога не трогает
- [x] Срок хранения удалённых записей: `memory.keep_days` в пакете, действует самый длинный; после срока `reins sweep` удаляет файл записи своего проекта; без срока файл остаётся
- [x] Поиск по словам: `reins memory find <слово>...` во всех проектах, по тексту, причине, местам и источнику
- [x] Поиск выдаёт короткие строки (текст до 300 знаков), полную запись даёт `reins memory show <номер>`
- [ ] Производный индекс: поиск читает все файлы записей при каждом вызове
- [x] Отпечаток каждого места записи, а не только первого; у места-каталога отпечаток это список имён в нём
- [x] Счётчики использования пишутся под блокировкой: одновременные отчёты счёт не теряют
- [x] Состояние проекта: запись `state` одна на проект, новая заменяет прежнюю; поля «что дальше» и «что не проверено»; состояние целиком в старте сессии
- [ ] Состояние не пишется само при закрытии задачи: его пишет агент в задаче сценария

Формат хранения менялся один раз: записи `.json` из каталога состояния больше не читаются. Настоящих записей в старом формате не было.
