# Пробная сессия: каждый хук в живом клиенте

Цель: за один час увидеть, что каждое событие клиента доходит до ядра. После сессии закрывается пункт «Каждый хук пройден в живом клиенте» списка `done.md`.

11.11.2026 шаги 1–5, 7, 8, 10 и 13 и раздел «Запуск без окна» пройдены в живом клиенте без окна: итог в `contracts.md`, раздел «Живой клиент». В клиенте с окном остались шаги 6, 9, 11 и 12: ответ человека «да», сценарий с публикацией в MR, сообщение «не проверено».

Плагины `agentic` и `exocortex` в этой сессии ещё включены. Вопросы о записи будут двойными: это ожидаемо.

## Перед сессией

1. Запомни число строк журнала:

```bash
wc -l ~/.local/state/reins/journal.jsonl
```

2. Запусти клиент из корня репозитория, где есть свой MR:

```bash
claude --plugin-dir ~/IdeaProjects/reins/clients/claude-code
```

## Шаги

Строки журнала смотри в своём терминале, не через агента: чтение состояния харнеса агентом даёт вопрос.

| № | Что сделать в сессии | Событие клиента | Что должно быть |
|---|---|---|---|
| 1 | Спроси агента: «что сказал reins при старте?» | SessionStart | Агент называет сценарии, записи памяти, прошлую сессию. Строка `harness.client_level_detected` с `level: full` |
| 2 | Задай любой вопрос | UserPromptSubmit | Строки `task.opened` и `task.kind_decided` с `kind: free` |
| 3 | Попроси прочитать файл | PreToolUse, чтение | Вопроса от reins нет |
| 4 | Попроси выполнить `git push --force origin HEAD` и ответь «нет» | PreToolUse, гейт | Вопрос от reins с правилом `git.*`. Строка `policy.decision` с `outcome: ask` |
| 5 | Попроси выполнить `echo x >> ~/.local/state/reins/journal.jsonl` | PreToolUse, защита | Отказ `protect.state`. Строка `policy.protected_attempt` с `outcome: deny` |
| 6 | Попроси выполнить `cat ~/.config/reins/config.json` и ответь «да» | PostToolUse | Строка `task.human_decision` с `decision: answered` |
| 7 | После шагов 3–6 посмотри расход | PostToolUse, расход | Есть строки `executor.cost` с `tokens` больше нуля. Если их нет: форма файла сессии клиента другая |
| 8 | Попроси запустить подчинённого агента на поиск по коду | PreToolUse для Agent, SubagentStop | Строки `executor.started` и `executor.report_received`. У действий подчинённого поле `executor: sub`. Если поля нет: клиент не даёт `agent_id` |
| 9 | Запусти `/reins:run mr-review mr_url=<свой MR>` | Сценарий | Задача доходит до `publishing`. Один вопрос на всю задачу при первой записи |
| 10 | Пока задача из шага 9 открыта, выполни `/compact`, затем спроси: «какую задачу держит сессия?» | PreCompact, SessionStart | Агент называет задачу и команду `reins input <задача>` |
| 11 | Скажи агенту закончить публикацию: `reins finish <задача>` | Конец сценария | Строка `task.closed` с меткой `verified_form` |
| 12 | Попроси поправить любой файл и не коммитить | Stop | Сообщение «not verified» после ответа агента |
| 13 | Выйди из клиента и запусти его снова | SessionEnd, SessionStart | Новый старт называет прошлую сессию: число запросов, вопросов, отказов |

## После сессии

1. Виды событий, которые дошли до журнала:

```bash
grep -o '"kind":"[a-z_.]*"' ~/.local/state/reins/journal.jsonl | sort | uniq -c
```

2. Сводка и восемь чисел:

```bash
reins status 1
```

3. Задержка хука. Время одного вызова с пустым входом это нижняя граница: запуск `node` и загрузка кода. На этой машине она была 0,13 с:

```bash
time (echo '{}' | node ~/IdeaProjects/reins/clients/claude-code/hooks/hook.ts post)
```

## Запуск без окна

Этот шаг отдельный: он тратит токены без тебя у экрана.

1. Добавь в `~/.config/reins/config.json` ключ `runner`. Команда проверена 11.11 с ключами `--model` и `--allowedTools`: добавь их под свою работу.

```json
"runner": ["claude", "-p", "{prompt}", "--plugin-dir", "/Users/yauhenirazhkou/IdeaProjects/reins/clients/claude-code"]
```

2. Запусти сценарий:

```bash
reins run mr-review mr_url=<свой MR>
```

3. Что должно быть: ответ с `ran: true` и кодом выхода клиента. Действие с вопросом попадает в очередь: `reins queue`.
