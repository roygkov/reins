# Сверка спецификации с agentic 0.5.8

История: состояние на 10.11.2026. Документ не обновляется. Это план переноса, а не описание кода: часть плана не сделана или сделана иначе. Верное состояние кода: `docs/contracts.md` и `docs/done.md`.

Дата: 2026-11-10. Источник: `agentic` тег `v0.5.8`, коммит `a4ba285`. Пути даны от `agentic/plugin`.
Метод: три независимых чтения кода (политика; журнал и задача; проверка и клиент), ключевые факты перепроверены по строкам.
Тесты `agentic` в этой сверке не запускались.

Объём: `lib` 6018 строк, `lib/memory` 1081 строка, тесты 9483 строки в 31 файле.

## 3. Совпадения модели и кода

Эти свойства спецификации уже работают в коде. Перенос сохраняет их.

| Свойство | Код |
|---|---|
| Вид задачи задают факты, а не слова | `kindOf`: gate ask даёт `prod`, классы файлов diff дают `code, text, question`. Токен `track=` в отчёте игнорируется | 
| Ответ проверки привязан к отпечатку рабочего состояния | Отпечаток: git tree по временному индексу, отслеживаемые и новые файлы. Stop требует `o.tree === cur` |
| Отчёт исполнителя это заявление | Stop читает из текста только строку `agentic-status:`. Возврат идёт по фактам |
| Правила как данные | `data/gate.json`: 49 правил, маркеры, защищённые ветки |
| Сомнение при записи ведёт к человеку | Сбой обработчика `pre-*` даёт выход 2. Нет Node: `ask` на каждый отфильтрованный вызов |
| Сомнение при чтении пропускает | Сбой остальных событий даёт выход 0 |
| Журнал только дополняется | `appendFileSync`, строки схемы 1 не переписываются |
| Проверка допущений о клиенте | `lib/host.js`: 18 допущений проверяются по входу хука, отказ пишет `host_check` и отключает возвраты Stop |
| Использование памяти считается по ссылке | Событие `mem_used` и метки `memused/` |
| Независимый рецензент без отчёта автора | Пакет ревью привязан к отпечатку и sha1 файла, счётчик `prompt_long` |

## 7. Решения владельца, 2026-11-10

| № | Решение | Что меняется |
|---|---|---|
| R1 | Правило «неизвестное считается записью» действует только для вызова инструмента. Команда оболочки вне опасных классов разрешена | Спецификация: `harness-connector`, страницы 2 и 6. Код `gate.js` для shell не меняется |
| R3 | Запись в производственное окружение утверждает человек на каждое действие | Код: `allow_forms` заменяется конвертом манифеста. Конверт на производственное окружение не действует |
| R6 | Задача включает шаг утверждения | Код: граница задачи в `state.js` и `main.js`. Ответ человека на вопрос задачи не открывает новую задачу |
| R14 | Ловушки и дела пишутся сами с окном вето. Решение возникает только из слов человека | Код: `memory/candidates.js`, `commands.js`. Запрет записи без человека снимается для G и T |

Остальные расхождения (R2, R4, R5, R7 - R13) решаются в пользу спецификации: меняется код.

Следствие R14 для экземпляра: правила `memory-autocommit: no` и human-only `decide|memory|wrapup` действуют, пока память ведут `agentic` и `exocortex`. Харнес заменяет их классами автономии после переноса памяти.
